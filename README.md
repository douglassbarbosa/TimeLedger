# TimeLedger

TimeLedger foundation project using Expo + React Native + TypeScript with a clean-architecture-inspired structure.

## Scripts

- `npm run start` - start Expo development server
- `npm run lint` - run ESLint checks
- `npm test` - run unit tests with Jest

## Structure

```text
src/
  domain/
  application/
  data/
  ui/
  shared/

tests/
  domain/
  application/
```
